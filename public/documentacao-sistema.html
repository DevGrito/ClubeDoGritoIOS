PARTE 1: VISÃO GERAL

1.1 O que é o Clube do Grito?

O Clube do Grito é uma plataforma digital completa para gestão de impacto social do Instituto O Grito. O sistema integra:

  • Captação de recursos (doações, assinaturas, patrocínios)
  • Gestão educacional (programas, cursos, alunos)
  • Gestão de eventos (ingressos, check-in, sorteios)
  • Transparência financeira (dashboards para conselho)
  • Engajamento de doadores (gamificação, benefícios)

PARTE 3: MÓDULOS DO SISTEMA

3.1 Módulo de Doações (Core)

Objetivo: Permitir que pessoas contribuam mensalmente com o instituto através de assinaturas recorrentes.

Funcionalidades

  • Cadastro de doadores via telefone (SMS)
  • Planos de assinatura mensal (R$ 30, R$ 50, R$ 100, R$ 200)
  • Processamento de pagamentos via Stripe
  • Histórico de doações
  • Certificados de doação

3.2 Módulo de Gamificação

Objetivo: Engajar doadores através de um sistema de pontos (Gritos) e recompensas.

Sistema de Gritos (Pontos)

Os doadores acumulam "Gritos" baseados em:

  • Valor da doação mensal
  • Tempo como doador
  • Indicações de novos doadores
  • Missões completadas

Benefícios

  • Sorteios exclusivos
  • Leilões de experiências
  • Acesso antecipado a eventos
  • Badges e conquistas

3.3 Módulo de Eventos e Ingressos

Objetivo: Gerenciar eventos do instituto com emissão de ingressos e controle de acesso.
  • Geração de ingressos com QR Code
  • Cotas para empresas patrocinadoras
  • Check-in via scanner
  • Controle de capacidade

3.4 Módulo PEC (Polo Esportivo Cultural)

Objetivo: Atender crianças e adolescentes com atividades de esporte e cultura no contraturno escolar.
  • Cadastro de atividades (Futebol, Música, Dança, etc.)
  • Matrículas de alunos
  • Controle de frequência
  • Avaliações físicas
  • Relatórios por turma

3.5 Módulo Inclusão Produtiva

Objetivo: Capacitar jovens e adultos para o mercado de trabalho através de cursos profissionalizantes.

Cursos Oferecidos

ÁreaExemplos
TecnologiaProgramação, Excel
BelezaManicure, Cabeleireiro
GastronomiaCulinária, Confeitaria
ArtesanatoCostura, Bordado
EmpreendedorismoGestão, Finanças
AdministrativoRecepção, Atendimento

3.6 Módulo Psicossocial

Objetivo: Acompanhamento de famílias em situação de vulnerabilidade social.
  • Cadastro de famílias
  • Registro de casos
  • Agendamento de atendimentos
  • Planos de acompanhamento
  • Indicadores de atenção social

3.7 Módulo Favela 3D (F3D)

Objetivo: Programa de desenvolvimento comunitário focado em 3 dimensões: Digital, Desenvolvimento e Dignidade.

3.8 Módulo Conselho (Dashboard Financeiro)

Objetivo: Oferecer transparência financeira para membros do conselho fiscal.

PARTE 8: FLUXOS DE USUÁRIO

8.1 Fluxo do Doador

1. DESCOBERTA └─► Acessa /entrar (link ou direto) 2. AUTENTICAÇÃO └─► Insere telefone → Recebe SMS → Valida código 3. ESCOLHA DE PLANO └─► R$30 (Semente) | R$50 (Raiz) | R$100 (Tronco) | R$200 (Fruto) 4. PAGAMENTO └─► Stripe Checkout (cartão de crédito) 5. CONFIRMAÇÃO └─► Assinatura ativada + Gritos creditados 6. ENGAJAMENTO └─► Benefícios | Missões | Sorteios | Impacto

8.2 Fluxo do Conselho

1. SOLICITAÇÃO └─► Preenche formulário (nome, email, justificativa) 2. APROVAÇÃO └─► Admin aprova → Papel "conselho" atribuído 3. ACESSO └─► /conselho (Dashboard read-only) ├─► KPIs de Impacto └─► Painel Financeiro
