Perfeito, entendi direitinho o problema. Hoje o cálculo está sempre olhando pra meta anual, mesmo quando você filtra por mês. Aí, óbvio, quase tudo fica vermelho até o fim do ano. Vamos arrumar isso.

Vou separar em 3 partes:

1. Regra de cor (vale pra mês e pra ano)

Vamos padronizar a lógica assim:

Verde → bateu ou passou a meta

Amarelo → ficou entre 80% e 99% da meta

Vermelho → ficou abaixo de 80% da meta

Em fórmula:

percentual = realizado / meta

se percentual >= 1        → verde
se 0.8 <= percentual < 1  → amarelo
se percentual < 0.8       → vermelho


Usando seu exemplo (meta do mês = 100):

Realizado = 150 → 150 / 100 = 1.5 (150%) → verde

Realizado = 99 → 99 / 100 = 0.99 (99%) → amarelo

Realizado = 50 → 50 / 100 = 0.5 (50%) → vermelho

2. Quando o filtro é MÊS (visão mensal)

Aqui a lógica muda a meta de referência:

Meta anual (macro): metaAnual = 1000

Número de meses com meta: mesesComMeta = 10

Meta do mês:

metaMes = metaAnual / mesesComMeta
       = 1000 / 10
       = 100


Então, na aba de impacto, quando o filtro está em um mês (por exemplo, janeiro):

Meta exibida = metaMes (100)

Realizado exibido = realizadoJaneiro

Cor = calculada com base em realizadoJaneiro x metaMes

Ou seja:

if (filtro === 'mes') {
  metaReferencia = metaMes[mesSelecionado]  // ou metaAnual / mesesComMeta
  realizadoReferencia = realizadoMes[mesSelecionado]
  cor = getCorMeta(realizadoReferencia, metaReferencia)
}

3. Quando o filtro é TODOS (visão anual + visão por mês)

Aqui dá pra fazer duas coisas ao mesmo tempo:

a) Card do ANO (macro)

Meta exibida = metaAnual

Realizado exibido = soma de todos os meses:

realizadoAnual = soma(realizadoMes[jan..dez])


Cor do ano = getCorMeta(realizadoAnual, metaAnual)

b) Cores de cada mês na visão "Todos"

Pelo que você falou:

"No em todos quando tiver a meta exemplo: se tiver ok fev, março, abril tem que estar verde, se não bateu a meta amarelo ou vermelho."

Ou seja, na visão Todos você quer:

Cada mês aparecendo com a meta do mês e o realizado do mês

Cada mês colorido individualmente (verde/amarelo/vermelho) pela meta mensal

Então:

if (filtro === 'todos') {
  // Card macro do ano
  metaAnualReferencia = metaAnual
  realizadoAnual = soma(realizadoJan..realizadoDez)
  corMacro = getCorMeta(realizadoAnual, metaAnualReferencia)

  // Lista de meses
  para cada mês m:
    metaMes = metaAnual / mesesComMeta   // ou metaMensal[m] se vier do banco
    realizadoMesM = realizado[m]
    corMes[m] = getCorMeta(realizadoMesM, metaMes)
}


Assim, em “Todos”, você enxerga:

Um card geral do ano (meta x realizado do ano, com cor do ano)

E cada mês com:

meta do mês

realizado do mês

cor própria (verde se bateu a meta, amarelo perto, vermelho longe)

4. Função pronta pra usar no código

Se você estiver em TypeScript/JavaScript, algo assim resolve:

type CorMeta = 'green' | 'yellow' | 'red';

function getCorMeta(realizado: number, meta: number): CorMeta {
  if (!meta || meta <= 0) return 'red'; // segurança

  const percentual = realizado / meta;

  if (percentual >= 1) {
    return 'green';    // bateu ou passou a meta
  } else if (percentual >= 0.8) {
    return 'yellow';   // entre 80% e 99%
  } else {
    return 'red';      // abaixo de 80%
  }
}


Depois é só garantir que:

No filtro de mês, você chama getCorMeta com realizadoMes, metaMes.

No filtro de todos, para:

Card do ano: getCorMeta(realizadoAnual, metaAnual)

Cada mês: getCorMeta(realizadoMes, metaMes).
