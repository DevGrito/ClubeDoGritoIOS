🚧 Tarefa: Carrossel de Cartões (Tela Financeira)
🎯 Objetivo

Implementar/ajustar o carrossel dos cartões salvos (Stripe) na tela financeira sem setas, com navegação 100% manual por swipe/drag, indicador por bolinhas e primeiro cartão = método de pagamento atualmente em uso.

✅ Requisitos funcionais (obrigatórios)

Swipe/Drag manual

Troca de cartão ao arrastar (touch e mouse).

Sem setas.

A troca deve atualizar um activeIndex em estado (React), e o cartão visível deve acompanhar esse índice.

Ordem dos cartões

Primeiro item da lista é o cartão em uso para o plano atual do usuário.

Demais cartões após o primeiro (pode ser por createdAt desc ou o que já usamos hoje).

Indicador (“bolinhas”)

Mostra a posição do cartão visível.

Apenas indicador (não é botão).

A bolinha do cartão ativo deve ficar com estilo “ativo” claro.

Estado sincronizado

activeIndex muda a cada troca (ex.: onSlideChange, onSelect, etc.).

O componente de cartão (número mascarado, brand, expiração) deve re-renderizar de acordo com o índice.

Compatibilidade

Funciona em mobile (touch) e desktop (mouse drag).

Sem “travamentos” por CSS (nada de pointer-events: none no wrapper; overflow só o necessário).

🎨 Requisitos de design

Sem gradiente (100% flat).

Cartão com cor sólida (usar nossa paleta — ex.: amarelo do Clube #FFC107 ou fundo claro com borda), bordas rounded-xl/2xl, sombra suave.

Tipografia legível; dados mascarados; ícones da bandeira (opcional, se já temos).

Espaçamento consistente; manter bolinhas centralizadas logo abaixo do carrossel.

Sem setas visíveis nem ocultas (não renderizar).

🔧 Implementação sugerida (pode ser Embla ou Swiper)

Preferência: Embla Carousel
 (leve e simples) ou swiper/react se já estiver no projeto.

Criar um wrapper CardsCarousel com:

cards: PaymentCard[]

currentCardId: string (id do cartão que está sendo usado no plano atual)

Estado activeIndex controlado pelo evento de troca.

Ordenação antes de renderizar: mover o currentCardId para a posição 0.

Checklist técnico interno:

Iniciar o carrossel com startIndex = 0.

onSelect → atualiza activeIndex com o índice real do slide ativo.

activeIndex → atualiza estilos das bolinhas.

Remover qualquer preventDefault indevido que bloqueie drag.

Garantir que o container de slides tenha largura fixa/auto por slide (ex.: flex: 0 0 100%).

🧪 Critérios de aceitação (QA)

Arrastar para esquerda/direita troca o cartão em mobile e desktop.

A primeira renderização mostra o cartão em uso (dados batem com o método atual do plano).

As bolinhas mudam conforme o cartão visível (sem delay).

Sem setas no DOM e no layout.

Ao mudar o conjunto de cartões (adicionar/remover), o carrossel recalcula o total e mantém o activeIndex consistente (clamp).

Sem “loop” infinito — ao chegar no último, para (não é carrossel circular).

🗂️ Estrutura esperada (exemplo)

components/finance/CardsCarousel.tsx (lógica do carrossel)

components/finance/CardItem.tsx (visual do cartão — sem gradiente)

components/finance/CardDots.tsx (bolinhas, leitura de activeIndex e total)

Ajustes na tela que consome o componente para enviar cards + currentCardId

🧩 Pseudocódigo (exemplo de contrato; não precisa ser essa lib)
const ordered = orderCards(cards, currentCardId); // current primeiro

const [activeIndex, setActiveIndex] = useState(0);
const { ref, scrollTo } = useEmblaCarousel({ loop: false, startIndex: 0 });

useEffect(() => {
  if (!embla) return;
  const onSelect = () => setActiveIndex(embla.selectedScrollSnap());
  embla.on('select', onSelect);
  onSelect();
  return () => embla.off('select', onSelect);
}, [embla]);

return (
  <div className="overflow-hidden" ref={ref}>
    <div className="flex">
      {ordered.map(card => <CardItem key={card.id} card={card} />)}
    </div>
  </div>

  <CardDots total={ordered.length} active={activeIndex} />
);


Estilo de cartão (exemplo Tailwind):
className="w-full h-[220px] rounded-2xl shadow-md bg-[#FFC107] text-slate-900 p-5 flex flex-col justify-between"

🚫 Não quero

Gradientes no cartão.

Setas (visíveis ou escondidas).

Dots clicáveis (apenas indicador).

📌 Observações finais

Se hoje o carrossel “não troca”, logar o índice no callback de seleção e provar que activeIndex muda. Se não mudar, é inicialização errada ou listener não registrado.

Verificar se algum wrapper tem CSS bloqueando o gesto (ex.: touch-action: none, overflow mal aplicado).
