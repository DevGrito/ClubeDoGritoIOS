Indicação com validação no app + pontos separados (não Gritos)

Quero um sistema de indicação no Clube do Grito com essas regras:

1) Conceito

Compartilhamento via link externo: https://clubedogrito.institutoogrito.com.br/?ref={refCode} (ou QR).

Nada é contado no clique.

A validação ocorre dentro do app quando o indicado faz cadastro + 1ª doação confirmada (Stripe).

Recompensa = 1 ponto de indicação (saldo separado, não soma ao programa de Gritos).

2) Código e captura

Cada usuário tem ref_code único (ex.: GRITO-AB12CD).

No acesso com ?ref=CODE, salvar somente localStorage.ref_code e ref_seen_at.

No signup, enviar ref_code (se existir) para associação pendente.

3) Banco de dados (Postgres/Drizzle)
-- Código único no usuário
ALTER TABLE usuarios ADD COLUMN IF NOT EXISTS ref_code TEXT UNIQUE;

-- Relação de indicação
CREATE TABLE IF NOT EXISTS indicacoes (
  id BIGSERIAL PRIMARY KEY,
  indicou_id UUID NOT NULL,        -- quem indicou
  indicado_id UUID UNIQUE NOT NULL,-- indicado (só conta 1 vez)
  ref_code TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'PENDENTE', -- PENDENTE | CONFIRMADA | EXPIRADA | INVALIDA
  criada_em TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  confirmada_em TIMESTAMPTZ,
  validade TIMESTAMPTZ NOT NULL    -- now()+interval '30 days'
);

-- Ledger separado de "Pontos de Indicação" (NÃO é Gritos)
CREATE TABLE IF NOT EXISTS indicacao_pontos_ledger (
  id BIGSERIAL PRIMARY KEY,
  user_id UUID NOT NULL,
  indicacao_id BIGINT NOT NULL REFERENCES indicacoes(id) ON DELETE CASCADE,
  pontos INTEGER NOT NULL,           -- ex.: 1
  motivo TEXT NOT NULL,              -- "indicacao_confirmada"
  criado_em TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (user_id, indicacao_id)     -- idempotência por indicação
);

-- Visão/sumário opcional
CREATE MATERIALIZED VIEW IF NOT EXISTS indicacao_pontos_saldo AS
  SELECT user_id, COALESCE(SUM(pontos),0)::int AS saldo
  FROM indicacao_pontos_ledger GROUP BY user_id;

4) Fluxo de backend

POST /api/auth/signup
Se ref_code válido:

Criar indicacoes com status='PENDENTE', indicou_id, indicado_id, validade = now()+30d.

Bloquear autoindicação.

POST /api/stripe/webhook (1ª doação confirmada do indicado)

Verificar indicação PENDENTE e dentro da validade.

Atualizar para CONFIRMADA + confirmada_em=now().

Creditar 1 ponto de indicação ao indicou_id criando linha no indicacao_pontos_ledger (usar transação e checagem UNIQUE para idempotência).

Não tocar no sistema de Gritos.

Importante: usar tabela de idempotência de eventos Stripe (ex.: stripe_events(id PRIMARY KEY, processed_at)) para não processar duas vezes.

5) Endpoints
GET  /api/indicacoes/minhas            -> lista [nome_indicado, criada_em, status, confirmada_em]
GET  /api/indicacao-pontos/saldo       -> { saldo }
GET  /api/indicacao-pontos/ledger      -> lista detalhada do histórico

6) UI no app (Perfil → “Indique e Ganhe”)

Card com seu código e link + botões Copiar e Mostrar QR.

Minhas Indicações: Nome, Data, Status (Pendente/Confirmada/Expirada).

Meus Pontos de Indicação: saldo total (esse saldo é independente dos Gritos).

Tooltip: “Conta somente após a primeira doação do indicado, até 30 dias do cadastro.”

7) Regras/Antifraude

Bloquear autoindicação (indicou_id === indicado_id).

Um indicado só pode validar 1 indicação.

Janela de 30 dias após cadastro (ou primeiro acesso com ref, se quiser guardar) para contar.

Rate limit por ref_code opcional.

8) Testes de aceitação

 Clique/scan não gera pontos.

 Signup com ref_code cria PENDENTE com validade=30d.

 1ª doação confirmada → CONFIRMADA + 1 ponto no ledger.

 Repetição de webhook não duplica (idempotência ok).

 Doação após 30 dias não conta (vira EXPIRADA).

 Autoindicação bloqueada.
